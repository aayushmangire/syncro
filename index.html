01 — The Crisis

Adding roads
makes traffic worse.

In 1968, mathematician Dietrich Braess proved that adding a new road to a congested network can increase total travel time for every single driver. It's not a paradox of theory — it happens in real cities, every day, when millions of GPS apps each optimize for one driver and ignore the system.

The gap between what selfish routing produces and what a coordinated system could achieve is called the Price of Anarchy. In practice, it means 25 million extra tons of CO₂, $87 billion in lost productivity, and 54 hours stolen from every commuter — each year, in the US alone.

The Braess network — the shortcut A→B makes everyone slower.

BPR Cost Function te(f) = t0 · (1 + 0.15 · (f / c)4) Bureau of Public Roads, 1964 — still the standard for link performance modeling

06 — Under the Hood

The equilibrium algorithm.

equilibrium.py 
def find_equilibrium(graph, trips, iterations=10):
    # Initialize edge flows to 0
    for edge in graph.edges:
        edge.flow = 0
        edge.time  = edge.free_flow_time

    # Method of Successive Averages
    for i in range(1, iterations + 1):
        batch_flow = {}

        for origin, dest, volume in trips:
            # Shortest path using CURRENT edge times
            path = shortest_path(graph, origin, dest, "time")
            for edge in path:
                batch_flow[edge] = batch_flow.get(edge, 0) + volume

        # Weighted average prevents oscillation
        for edge in graph.edges:
            edge.flow = ((i - 1) * edge.flow + batch_flow.get(edge, 0)) / i

            # BPR function: recalculate travel time
            edge.time = edge.free_flow_time * (
                1 + 0.15 * (edge.flow / edge.capacity) ** 4
            )

    return graph
